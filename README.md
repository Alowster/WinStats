# WinStats

Herramienta de escritorio para Windows que muestra en pantalla estadísticas y datos de uso en tiempo real de los componentes del ordenador: CPU, RAM, GPU y más.

## Características

- Monitorización en tiempo real de componentes del sistema
- Interfaz gráfica ligera
- Disponible como ejecutable `.exe`, sin necesidad de instalar Python

## Tecnologías

- **Python**
- **PyInstaller** — empaquetado como ejecutable Windows

## Uso

Descarga el ejecutable desde [Releases](https://github.com/Alowster/WinStats/releases) y ejecútalo directamente.

Para correr desde el código fuente:

```bash
git clone https://github.com/Alowster/WinStats.git
cd WinStats
python app.py
```

## Requisitos (solo para ejecutar desde código)

- Python 3.x
- Windows
